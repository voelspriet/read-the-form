How this works, and what it refuses to do. GLM-5.3-Flash is given one job: read the characters in each box. It is never asked what a code means. Meaning comes from the FAA's own published lookup tables.

That split is the point. Asked to interpret, a model will produce a plausible expansion for a code it has never seen, and it will not tell you it guessed. Anything the FAA's tables do not cover stays on screen as the raw code, in red.

Codes and comparison reports come from aircraftdefects.com, which holds every Service Difficulty Report the FAA has published since 1995.
